## repos_get
Get a repository's metadata (default branch, visibility, open issue count, topics).
Args: owner, repo (required).
Example: repos_get({"owner":"octocat","repo":"hello-world"})

## issues_list_assignees
List the users who are eligible to be assigned to issues in a specific repository. This returns the repository's assignable users, not the users currently assigned to a particular issue.
Args: owner, repo (required); per_page, page.
Example: issues_list_assignees({"owner":"octocat","repo":"hello-world"})

## repos_list_branches
List branch names and protection status in a repository. Use this to check whether a named branch exists; it does not return commit history.
Related: repos_get_branch (one branche by id).
Args: owner, repo (required); protected, per_page, page.
Example: repos_list_branches({"owner":"octocat","repo":"hello-world"})

## repos_get_branch
Get one branch with its latest commit.
Related: repos_list_branches (find branches).
Args: owner, repo, branch (required).
Example: repos_get_branch({"owner":"octocat","repo":"hello-world","branch":"branch_1"})

## repos_list_commits
List commits in a repository, newest first. To show recent commits from a branch, pass that branch name in `sha`; omit `sha` to use the default branch.
Args: owner, repo (required); sha, path, author, since, until, per_page, … (1 more).
Example: repos_list_commits({"owner":"octocat","repo":"hello-world"})

## issues_list_for_repo
List issues (and pull requests, which GitHub returns through its issues API) in a repository. By default, returns open items.
Related: issues_get (one issue by id), issues_create (create an issue).
Args: owner, repo (required); milestone, state, assignee, creator, mentioned, labels, … (5 more).
Example: issues_list_for_repo({"owner":"octocat","repo":"hello-world","labels":"bug"})

## issues_create

Related: issues_get (one issue by id), repos_get (one {owner} by id).
Args: owner, repo, title (required); body, assignee, milestone, labels, assignees.
Example: issues_create({"owner":"octocat","repo":"hello-world","title":"Example"})
